01 Aug 2026

Interview Question Generator

Web app · Devstorm Hackathon

Candidates preparing for a role usually have exactly one artefact to work from — the job description — and no structured way to turn it into practice. This tool closes that gap: paste a JD, and it returns a categorised set of technical and behavioural questions drawn from the skills and responsibilities the posting actually names.

Approach
The JD is parsed for role signals and keywords, matched against a curated JSON question bank, then grouped into technical and behavioural tracks so a candidate can rehearse one dimension at a time.
Constraint
36 hours, start to demo. No backend and no framework — everything runs client-side, which kept the build shippable inside the window and the app instant to load.
Team
Built collaboratively — design, implementation and the final presentation to judges were all shared work.

02 Apr 2026

Pomodoro Timer Machine

Hardware · Electronics project

A physical take on the Pomodoro technique. Phone-based timers fail for the obvious reason — the timer lives on the device you are trying not to look at. This one is a standalone machine that sits on the desk and runs the cycle without asking for attention.

Behaviour
Timed work intervals hand off automatically to scheduled breaks and back again, so a full session runs end to end without the user resetting anything mid-flow.
Why it matters
Automating the interval transition is the whole point of the technique; doing it in hardware removes the device that causes the distraction in the first place.
  • Embedded logic
  • Timer circuits
  • Interval scheduling
03 Nov 2025

SONAR Return Classification

Data analysis · Physics project

The SONAR dataset is a genuinely hard little problem: each sample is a set of energy readings across frequency bands from a sonar chirp bounced off an object on the sea floor, and the task is to say whether what it hit was a metal cylinder or a rock. The signal is real, the classes overlap, and the sample count is small.

Preprocessing
Cleaned and prepared the dataset in Python with Pandas and NumPy — checking class balance, band-by-band distributions and correlation structure before touching a model.
Modelling
Built and evaluated a baseline classifier to separate the two object types, then interpreted the results rather than stopping at an accuracy figure — which bands carried the separation, and where the model got confused.
Takeaway
Most of the useful work happened in the exploratory phase. The model was the short part.
  • Python
  • Pandas
  • NumPy
  • EDA
  • Classification
